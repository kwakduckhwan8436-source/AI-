# 부의 로드맵 · AI 재테크 연구소

한국형 부업·투자·절약 진단 웹앱과 **월급 포트폴리오 설계** 도구입니다. 모든 것이 브라우저에서만 동작하는 정적(static) 사이트라 서버가 필요 없습니다.

## 📁 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 메인 앱 — 맞춤 진단(1,300여 개 부업·투자 카탈로그), 대시보드, 카테고리, 용어사전, 자산관리, 문의 게시판 |
| `portfolio.html` | **월급 포트폴리오 설계** (별도 페이지) — 월급을 넣으면 부채·비상금·안전·성장·부업 종잣돈까지 자동 배분 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서빙하도록 하는 빈 파일 |
| `README.md` | 이 문서 |

## 🔗 두 페이지의 연동 방식

두 파일은 **같은 폴더(같은 도메인)** 에 올리면 자동으로 데이터를 공유합니다.

- 메인 앱에서 **맞춤 진단**을 실행하면 소득·성향·나이·부채·목표가 브라우저(`localStorage`)에 저장됩니다.
- `portfolio.html`을 열면 그 값이 자동으로 채워지고, 여기서 바꾼 값도 다시 저장됩니다.
- 포트폴리오의 추천 종목 카드와 **← 부의 로드맵** 버튼은 `index.html?tab=N` 형태로 메인 앱의 해당 카테고리로 이동합니다.

> 두 파일을 **다른 도메인**에 나눠 올릴 경우, `portfolio.html` 상단의 `var MAIN_URL='index.html';` 한 줄을 메인 앱의 실제 주소로 바꿔주세요. (localStorage 자동 공유는 같은 도메인에서만 됩니다.)

## 🚀 GitHub Pages로 올리기

1. 이 폴더의 파일 전체를 새 저장소(repository)에 업로드합니다.
2. 저장소 **Settings → Pages** 에서 Branch를 `main`(또는 `master`) / `/root` 로 지정하고 저장합니다.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 에서 메인 앱이, `.../portfolio.html` 에서 포트폴리오가 열립니다.

`index.html`이 저장소 최상단(root)에 있으면 기본 주소로 바로 열립니다.

## ⚠️ 안내

- 교육·참고용 도구이며 개별 투자 조언이 아닙니다. 투자·부동산·창작물은 원금 손실 위험이 있습니다.
- 모든 데이터는 사용자의 브라우저 안에만 저장되며 외부로 전송되지 않습니다.
- 링크는 각 서비스 공식 페이지로 연결되며 제휴·광고 관계가 없습니다.
